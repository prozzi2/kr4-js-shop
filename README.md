## Запуск

Откройте index.html в браузере. Для одинакового поведения localStorage на всех страницах рекомендуется локальный сервер из папки проекта:

```sh
python3 -m http.server 8000
```

Затем откройте http://localhost:8000. Установка npm-пакетов и сборка не требуются.

## Структура

- index.html — главная; catalog.html — интерактивный каталог.
- product.html?id=9 — выбранный товар; неизвестный id показывает сообщение об отсутствии товара.
- order.html?product=9 — заявка на выбранный товар.
- cart.html — корзина; contacts.html — контакты; onas.html — о магазине.
- css/style.css и css/responsive.css — оформление и адаптация.
- images/ — локальные JPEG/WebP разных размеров.
- js/data.js — единственный исходный массив из 10 товаров, три категории, цены и расчёт скидок.
- js/catalog.js — создание карточек, состояние каталога, поиск, фильтры и сортировка.
- js/validation.js — проверка заявки и сообщения рядом с полями.
- js/storage.js — чтение/запись JSON с обработкой ошибок localStorage.
- js/cart.js — корзина, количество, сумма, промокоды и синхронизация вкладок. В файле также сохранены вспомогательные функции избранного; отдельного интерфейса избранного нет.
- js/feedback.js — сообщения о действиях в области role=status.
- js/kr3-scripts.js — сохранённое меню, модальное окно, контакты, страница товара и сводка заявки. Совместимое представление PRODUCTS строится из products, отдельной базы товаров нет.
- js/main.js — примеры map/filter/reduce и статистика магазина.

## Обязательная функциональность

Карточки генерируются через createElement и append. В каждом объекте товара одинаковые свойства: id, title, category, gender, price, discountPercent, rating, isAvailable, image, alt, badge, description, specs.
Поиск работает по названию без учёта регистра через input и includes. Фильтрация через filter последовательно применяет категорию, пол, максимальную цену со скидкой и наличие. Сортировка по цене, названию или рейтингу выполняется на копии массива: исходные данные не меняются. Есть счётчик, пустое состояние и полный сброс фильтров и сортировки.

Форма проверяет выбранный доступный товар, целое количество 1–10, имя от двух символов, e-mail, телефон из 11 цифр с начальной 7 или 8, согласие. Ошибки связаны с полями через aria-describedby; первое ошибочное поле получает фокус. Используются события click, input, change, submit, blur и reset. Отправка отменяется через preventDefault: это учебный проект без backend.

## Самостоятельные доработки

Корзина сохраняется в localStorage, поддерживает изменение количества, удаление, очистку и счётчик. При загрузке проверяются типы, существование товаров, наличие и количество; дубликаты объединяются с лимитом 10. Промокоды ARM10 и STUDENT5 дают 10% и 5%; применяется один код. Дополнительно реализованы фильтры по полу, цене, наличию, сортировка по рейтингу, карточки комплектов, responsive images, сообщения без alert и синхронизация корзины между вкладками.

Заявка оформляется на один товар отдельно от корзины. Состав корзины и промокод в заявку не переносятся. Доставка заявки стоит 500 ₽ при сумме менее 30 000 ₽, иначе бесплатно; самовывоз бесплатный.

## Безопасный вывод

Текст, введённый пользователем, выводится через textContent. Нет inline-обработчиков и вставки пользовательских данных через innerHTML. Повреждённый JSON или недоступное хранилище не останавливают страницу. Контактные данные не сохраняются. Сообщение об успехе явно указывает, что данные не отправлены.
