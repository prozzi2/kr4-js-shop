Тема: «JavaScript: интерактивность, DOM, события, формы и валидация».

Дисциплина: «Фронтенд и бэкенд разработка».

## Основа проекта

Проект `kr4-js-shop` создан на основе собственного магазина из КР №3.

В качестве основы используется адаптивная версия HTML/CSS-интернет-магазина из контрольной работы №3
(`kr3-responsive-shop`). Скрипт КР №3 временно сохранён в `js/kr3-scripts.js`.

## Примечание к безопасности

Пользовательские данные, данные формы, данные из `localStorage` и данные будущего API не вставляются через `innerHTML`.
Для текстового вывода используется `textContent`.

## Примечание к контрольной работе №4

Массив товаров расширен до 10 позиций и соответствует теме магазина Shop_ot_bob.

## Принцип безопасного вывода данных

Для вывода пользовательских данных и данных, которые в будущем могут прийти из формы, `localStorage` или API,
используется `textContent`, а не `innerHTML`.

`innerHTML` разбирает строку как HTML: строка `<img src=x onerror=alert(1)>` превратится в настоящий элемент,
и его код выполнится. `textContent` показывает ту же строку как обычный текст.
